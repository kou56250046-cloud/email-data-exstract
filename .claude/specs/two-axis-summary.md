# 2軸分類（主＝業務の段階 × 副＝設備・工種）と集計画面

## Context
- 既存ツール（`src/page.html` + `js/*.js` → `node build.mjs` で 1 ファイルの `index.html`）は、カテゴリを 1 軸だけで付けている
- ユーザーの要望: 主カテゴリ（業務の段階）と副カテゴリ（設備・工種）の 2 軸に分け、主×副の集計表を見たい
- ヒヤリング結果:
  - 主カテゴリ＝業務の段階（依頼→見積→発注→完了→請求）
  - 副カテゴリは 1 通に 1 つ
  - 集計は 4 つすべて欲しい: 主×副の集計表 / 月別推移 / SS 別集計 / 集計表の CSV 書き出し
  - 添付 PDF は **FAX を PDF にしたもの（中身は画像）**で、内容は Excel と同じ → 文字は取り出せない
- 規模 M（新しいデータ構造・設定の移行あり）

## 受入条件
1. **2 軸の分類**: 1 通に主カテゴリ 1 つと副カテゴリ 1 つを付ける。どちらも「ルールで自動分類＋手で修正」。手で付けた方がルールより優先。どちらも当てはまらなければ「未分類」
2. **初期設定**（画面で自由に変えられる）
   - 主: 対象外（パスワード・自動通知）/ 補修依頼 / 見積 / 発注 / 完了報告 / 請求 / その他
   - 副: 計量機（計量機・給油機・ノズル・給油ホース・表示器）/ 洗車機 / 看板・照明（看板・サイン・照明・キャノピー・LED）/ POS・電気（POS・レジ・分電盤・ブレーカー・配線）/ タンク・配管（タンク・液面計・配管・漏洩・油水分離）/ 空調・コンプレッサー / 建物・舗装（防火壁・舗装・屋根・外壁・トイレ・排水）/ その他設備
   - 副のルールは件名・本文に加えて添付 xlsx の中身を見る（「対象設備」欄で決まることが多いため）
3. **設定の移行**: 既存の設定（1 軸のカテゴリ・ルール・手直し）は主カテゴリへ自動で引き継ぐ。既存の「見積・請求」は「見積」として引き継ぐ。読み込み済みの設定ファイル（v1）も読み込める
4. **SS 名の取り出し**
   - 添付 xlsx の「SS名 / 店舗名 / 給油所名 / 施設名」（見出し語は設定で変更可）の隣のセルから取る
   - 無ければ件名・本文から「○○SS」「○○給油所」「○○サービスステーション」の形を探す
   - 表記をそろえる（全角半角・空白）。詳細画面で手で直せ、手直しは保存される
5. **画面**
   - 一覧に主・副の 2 つのチップと SS 名を出す。左のカテゴリ一覧は主カテゴリ
   - 絞り込み欄に「副カテゴリ」「SS」を追加
   - 詳細画面に主・副の選択欄と SS 名の入力欄。どの語で分類されたかを軸ごとに出す
   - 一括変更で軸を選べる
6. **集計画面**（「一覧 / 集計」の切り替え）。期間・検索・送信者などの絞り込みが集計にもかかる。「対象外」は既定で除く（切り替え可）
   - 主×副の集計表: 件数・行と列の合計・件数に応じた濃淡。マスのクリックで、その条件の一覧へ移る
   - 月別推移: 行＝月、列＝主カテゴリ、件数と合計。合計は横棒で示す（CSS のみ）。月はメールの日付で数える
   - SS 別: 行＝SS、列＝主カテゴリ＋合計。件数の多い順。SS 名のクリックで一覧へ移る。SS 名が取れなかったメールは「（SS 不明）」
   - 3 つの表それぞれに「CSV で書き出す」（UTF-8 BOM 付き）
7. **添付 PDF**
   - 詳細画面で PDF を表示できる（ブラウザ内蔵の PDF 表示）。うまく表示できない環境では「新しいタブで開く」「保存」
   - 一覧で xlsx と同じように「pdf」の印を出す
   - 添付の絞り込みに「PDF あり（xlsx なし）」を足す。文字を読めないので手で分類が必要なメールをまとめて探すため
8. **書き出しの変更**
   - CSV: 「カテゴリ」を「主カテゴリ」「副カテゴリ」「SS名」の 3 列にする。「添付PDF」（ファイル名）を足す
   - 閲覧用 HTML: 主カテゴリ別に分け、各メールに副カテゴリと SS 名を出す
   - JSON: mainCategory / subCategory / ss を出す
9. 使い方に 2 軸の分類・集計画面・PDF の扱いを追記する
10. 外部へ通信しない（現状どおり）。`index.html` 1 ファイルで動く（現状どおり）

## 非目標
- PDF の文字の取り出し・OCR（FAX は画像なので取り出せない。OCR は依存とサイズが大きすぎる）
- 1 通に副カテゴリを複数付けること
- SS の別名をまとめる名寄せ表（「本町SS」と「本町店」を同じとみなす等）。表記ゆれをそろえるところまで
- グラフ描画ライブラリ。棒は CSS の幅だけで描く
- 主×副以外の任意の組み合わせを選べる集計（副×SS、送信者別など）
- 3 軸目以降のカテゴリ

## 設計
### データ
- 設定 v2: `{ version: 2, axes: { main: {categories, rules}, sub: {categories, rules} }, ssLabels: string[] }`
- 手直し v2: `manual[key] = { main?: catId, sub?: catId, ss?: string }`
  - v1（`manual[key] = catId`）は `{ main: catId }` に変換する
  - v1 の設定は `axes.main` にする。「見積・請求」の ID は `c-estimate` のまま「見積」に改名する
- メールの分類結果は `m.cls = { main: {categoryId, by, ruleId, hits}, sub: {...} }`、SS 名は `m.ss = { name, by: 'manual'|'xlsx'|'text'|null }`
- `exclude`（書き出しから外す）は主カテゴリにだけ持たせる

### ファイル
| ファイル | 変更 |
|---|---|
| `js/classify.js` | `classify(mail, rules, manualId)` に変更（手直しの値を直接受け取る）。`defaults()` を `{main, sub}` の 2 軸にする。`migrate(settings, manual)` を追加 |
| `js/fields.js`（新規） | `extractSs(mail, labels)`: xlsxText の「見出し\t値」の行と、件名・本文の正規表現から SS 名を取る |
| `js/summary.js`（新規） | 純粋関数 `matrix(rows, mainCats, subCats)` / `monthly(rows, mainCats)` / `bySs(rows, mainCats)` / `tableToCsv(header, rows)`。Node でテストできる |
| `js/export.js` | 列の変更（主・副・SS・添付PDF）、HTML の見出しに副と SS |
| `js/app.js` | 2 軸の state、分類の再計算、一覧・詳細・一括変更・絞り込み、設定画面の軸タブ、集計画面の描画、PDF 表示、移行の呼び出し |
| `src/page.html` | 一覧/集計の切り替え、副・SS の絞り込み、詳細の選択欄 2 つと SS 入力、設定画面の軸タブ・SS 見出し語、集計画面の枠、使い方の追記、`fields.js`・`summary.js` の読み込み |
| `css/style.css` | 集計表（濃淡・横棒）、チップ 2 つ、タブ |
| `build.mjs` | 変更なし（新しい script も自動で埋め込まれる）。CSP に PDF 表示に必要な指定が要るかブラウザで確かめ、要るなら最小限で足す |
| `tests/` | classify（2 軸・移行）、fields（SS 抽出）、summary（集計・CSV）、export（列）のテストを追加・更新。`make-samples.mjs` に FAX 風 PDF（画像 1 枚の PDF）だけが付いたメールと、発注・請求のメールを足す |

### 再利用するもの
- `MsgClassify.matchRule` / `norm`（表記をそろえる処理）: そのまま 2 軸に使う
- `MsgExport.csvCell` 相当の CSV 作成: 集計表の CSV にも使う（`summary.tableToCsv` は同じ規則に合わせる）
- `app.js` の `renderSettings()`: 軸を引数で受け取る形に変えて、主・副の両方に使う
- `app.js` の `xlsxTextOf()`: SS 抽出の入力（xlsxText）として流用する
