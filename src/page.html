          対象

          CSV は Excel でそのまま開けます（UTF-8 BOM 付き）。本文が 32,000 文字を超える場合は切り詰めます。添付ファイルの中身は含まれません。詳細画面から個別に保存してください。

          使い方

          1. 読み込む 2. 見る・探す 3. 分類する 4. 集計する 5. 書き出す 6. AI に渡すとき 7. データの扱い 8. うまくいかないとき

          1. 読み込む

          • 「フォルダを選ぶ」で、.msg が入ったフォルダを読み込みます。下の階層のフォルダも含みます。
          • 複数のフォルダを読み込む: それらのフォルダが入っている親フォルダを選ぶと、中のフォルダが件数つきの一覧で出ます。読み込みたいフォルダにチェックを入れて「読み込む」を押します（ブラウザの選択画面では一度に 1 フォルダしか選べないため、この形にしています）。
          • フォルダを選ぶと、ブラウザが「ファイルをこのサイトにアップロードしますか？」と確認します。ブラウザの決まった表示で、実際には外部へ送られず、この PC の中で読むだけです。
          • 「ファイルを選ぶ」で 1 件ずつ、または画面へのドラッグ＆ドロップでも読み込めます。
          • 続けて別のフォルダを読み込むと一覧に追加されます。同じファイルは二重に読み込みません。
          • 壊れたファイルや .msg でないものは、左の「読めなかったファイル」に入ります。全体の読み込みは止まりません。
          • 同じメール（Message-ID が同じ、または中身が同じ）が別々のファイルに入っている場合、一覧に「重複」と出ます。左の「すべて」はファイルの数で、その下に重複を除いた件数を出します。絞り込みの「重複」で、1 件にまとめて表示したり、重複しているものだけを見たりできます。
          • 同じファイルを二度読み込むことはありません（フォルダの選び方が違っても、ファイル名・サイズ・更新日時が同じなら読み込み済みとして飛ばします）。

          2. 見る・探す

          • 一覧の行をクリックすると、右側に詳細が開きます。↑↓（または kj）で前後のメールへ移れ、Esc で閉じます。
          • 詳細では、宛先（To / Cc / Bcc）・送受信日時・本文・添付を確認できます。本文は「見たまま（HTML）」と「テキスト」を切り替えられます。
          • 添付の xlsx は「表を見る」で中身を表示できます。PDF は「PDF を表示」で中身を見られます（表示されない場合は「新しいタブで開く」）。画像は縮小表示され、クリックで拡大します。どの添付も「保存」で取り出せます。
          • 転送されたメール（メールの中のメール）は、「添付メール」を開くと中身まで見られます。
          • 上の検索欄は、件名・本文・送信者・宛先・添付ファイル名・添付 xlsx の中身をまとめて探します。空白で区切ると「すべてを含む」で絞り込みます。全角と半角、大文字と小文字の違いは区別しません。
          • 副カテゴリ・SS・送信者・期間・添付の有無でも絞り込めます。添付の「PDF あり（xlsx なし）」は、FAX の PDF しか付いていないメール（文字を読めないので手で分類が必要なもの）をまとめて探すときに使います。
          • 一覧の「日時」「送信者」「件名」をクリックすると並べ替えます。

          3. 分類する

          1 通のメールに、次の 2 つのカテゴリと SS 名が付きます。

          • 主カテゴリ（業務の段階）: 対象外（パスワード・自動通知）/ 補修依頼 / 見積 / 発注 / 完了報告 / 請求 / その他
          • 副カテゴリ（設備・工種）: 計量機 / 洗車機 / 看板・照明 / POS・電気 / タンク・配管 / 空調・コンプレッサー / 建物・舗装 / その他設備。件名・本文に加えて添付 xlsx の中身（「対象設備」欄など）も見て決めます
          • SS 名: 添付 xlsx の「SS名」欄の値。無ければ件名・本文の「○○SS」「○○給油所」から取ります
          • 読み込むと、「分類の設定」のルールに従って軸ごとに自動で分類されます。ルールは上から順に調べ、最初に当てはまったものが使われます。
          • カテゴリの名前・色・並び順・ルールは、「分類の設定」の上のタブ（主カテゴリ / 副カテゴリ / SS 名の取り出し）で軸ごとに変えられます。
          • 「補修依頼」「修理依頼」のように言い方が違う場合は、ルールの語を , で区切って並べます（例: 補修, 修理, 修繕）。どれか 1 つでも含まれれば当てはまります。
          • 詳細画面に「どの語で分類されたか」が出ます。間違って分類されていたら、その語をルールから外すか、より上に別のルールを置いてください。
          • 1 件だけ直す: 詳細画面の上にある主・副の欄で選び直します。「自動」を選ぶとルールによる分類に戻ります。SS 名は右の欄に入力します（空にすると自動に戻ります）。
          • まとめて直す: 一覧のチェックボックスで選び、上に出る欄で「主カテゴリを / 副カテゴリを」とカテゴリを選んで「にする」を押します。
          • FAX の PDF しか付いていないメールは中身の文字を読めないため、件名・本文だけで分類されます。添付の絞り込みで「PDF あり（xlsx なし）」を選び、PDF を見ながら手で直してください。
          • 手で付けたカテゴリには「手」の印が付き、ルールより優先されます。
          • 「分類の設定」の「よく来る送信者ドメイン」から、送信元の会社ごとのルールを簡単に作れます。

          4. 集計する

          • 一覧の上の「集計」タブで切り替えます。左の主カテゴリ・上の絞り込み条件（期間・SS など）がそのままかかります。「書き出しから外す」カテゴリ（対象外）は、チェックを入れない限り数えません。
          • 主カテゴリ × 副カテゴリ: 件数と行・列の合計。件数が多いマスほど濃く表示します。
          • 月別の推移: 月ごとの件数を主カテゴリ別に並べ、合計を横棒で示します。
          • SS 別: SS ごとの件数を主カテゴリ別に、多い順で並べます。SS 名が取れなかったメールは「（SS 不明）」にまとめます。
          • 同じメールが複数のファイルにある場合は、1 件として数えます。
          • 数字・月・SS 名をクリックすると、そのメールの一覧へ移ります（一覧も重複を 1 件にまとめた表示になり、件数が集計と一致します）。
          • それぞれの表の「CSV で書き出す」で、Excel に貼れる形で保存できます。

          5. 書き出す

          「書き出し」から、対象（絞り込み中 / 選択中 / すべて）と形式を選びます。「書き出しから外す」にしたカテゴリ（初期設定では「対象外」）は、チェックを入れない限り含まれません。

          形式中身向いている用途注意
          CSV（Excel） 1 通 = 1 行の表。主カテゴリ・副カテゴリ・SS名・分類方法・送受信日時・送信者・To / Cc / Bcc・件名・本文・添付ファイル名・添付PDF・添付 xlsx の内容・重要度・Message-ID・元ファイル名など 22 列。 Excel で並べ替え・フィルタ・集計する。スタンド別・月別の件数を数える、一覧表として台帳に貼る。 本文は 32,000 文字で切り詰め。= などで始まる値は数式にならないよう先頭に ' を付けます。
          閲覧用 HTML 主カテゴリ別の目次つき 1 ファイル。1 通ずつ件名・副カテゴリ・SS・送信者・日時・宛先・添付名・本文を並べます。添付 xlsx の内容は折りたたみで表示。 ブラウザでざっと読む、印刷して回覧する、Outlook を持たない人に共有する。 集計には不向き。本文は文字だけ（画像・装飾は含みません）。
          JSON 全項目をそのまま入れた構造化データ。宛先は名前とアドレスの組、添付は名前・サイズ・種類の一覧。本文の切り詰めなし。 AI に読ませる、別のプログラムやツールに取り込む、データとして保管する。 人がそのまま読むには不向き。

          どの形式にも、添付ファイルそのもの（画像・PDF など）は含まれません。xlsx だけはセルの文字をテキストにして入れます（1 通あたり最大 5 万文字）。FAX の PDF は画像のため文字は入りません。添付が必要なときは詳細画面から保存してください。集計表の CSV は「集計」タブから書き出します。

          6. AI に渡すとき

          • JSON がおすすめです。項目の区切りがはっきりしていて、本文の切り詰めや文字の付け足しがありません。
          • 件数が多いと一度に渡せる量を超えます。左のカテゴリ（例: 補修依頼だけ）や期間で絞り込んでから「絞り込み中」で書き出し、何回かに分けて渡してください。
          • AI に渡すと、メールの中身が外部のサービスに送られます。送ってよい内容か、社内の取り決めを確かめてください。
          • 画像の中身は書き出しに入りません。AI に見せたい場合は、詳細画面から保存して別に添付してください。

          7. データの扱い

          • .msg ファイルはこのパソコンの中で読むだけで、外部へは一切送信しません。メール本文の外部画像も読み込みません。
          • メールの中身は保存しません。画面を閉じると一覧は消えるので、次回はもう一度フォルダを読み込んでください。
          • カテゴリ・ルール・手で付けた分類は、このブラウザに自動で保存されます。同じファイルを読み込み直すと、手で付けた分類も戻ります。
          • 別のパソコンやブラウザへ移すときは、「分類の設定」→「設定を書き出す」で保存したファイルを、移した先で「設定を読み込む」から読み込みます。
          • ほかの人にツールを渡す: 右上の「このツールを保存」で、ツール本体を 1 つの HTML ファイルとして保存できます。そのファイルをダブルクリックすればそのまま使えます（インストール不要）。読み込んだメールや分類の設定は入りません。

          8. うまくいかないとき

          • 文字化けする: 「テキスト」と「見たまま（HTML）」を切り替えてみてください。それでも化ける場合は、そのメールの送信元を控えてご相談ください。
          • 分類がおかしい: 詳細画面で「どの語で分類されたか」を確認し、「分類の設定」でその語を直します。
          • SS 名が取れない・違う: 「分類の設定」→「SS 名の取り出し」で、xlsx の見出し語（例: 店舗名）を足します。個別には詳細画面の SS 欄に入力します。
          • PDF の中身で分類されない: FAX の PDF は画像なので文字を読めません。手で分類してください。
          • xlsx が表示されない: 古い形式の .xls（Excel 2003 以前）は表示できません。「保存」して Excel 等で開いてください。Word・PDF の中身も表示しません。
          • 動作が重い: 一覧を 100 件ずつ表示しています。絞り込みを使うと軽くなります。
