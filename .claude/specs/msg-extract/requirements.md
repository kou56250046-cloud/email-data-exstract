# .msg メール抽出・分類ツール（依存ゼロ HTML）

## Context
- 受け取った .msg（Outlook のバイナリ形式）が1000件以上あるが、有償版 Outlook がないため中身を確認できない
- ブラウザで開く HTML 1枚で .msg を解析し、一覧表示・カテゴリ分類・書き出しを行う
- 規模 M（新しいデータ構造あり）。テンプレは `static-zero`（依存ゼロ・`file://` で開ける・オフライン）
- ヒヤリング結果: 分類＝ルール自動＋手で修正 / カテゴリ＝画面で作る / 出力＝CSV・閲覧用HTML・JSON / 実物サンプルは提供不可（機密）

## 受入条件
1. 複数の .msg（フォルダごと可）をドロップすると全件を解析して一覧表示する。1000件で固まらない（逐次処理＋進捗表示）
2. 抽出項目: From（表示名＋アドレス）/ 送信日時 / 受信日時 / To / Cc / Bcc / 件名 / 本文（テキスト・HTML・RTF圧縮から復元）/ 添付ファイル名・サイズ・種類 / 添付ファイル本体 / Message-ID・In-Reply-To / 重要度 / 元ファイル名
3. 添付ファイルは詳細画面から個別に保存できる。添付された .msg は中まで展開して表示する
4. 日本語が化けない（Unicode 版プロパティ優先、ANSI 版は CodePage プロパティ→Shift_JIS 等で TextDecoder 復号）
5. HTML 本文は sandbox 付き iframe で表示し、スクリプト実行・外部画像の読み込みをしない
6. カテゴリを画面で追加・改名・削除できる。ルール（条件: 送信者アドレス/ドメイン・件名・本文・添付有無 × 含む/一致、優先順）で自動分類し、一覧で1件ずつ・複数選択でまとめて手直しできる。手直しはルールより優先
7. 検索（全文）・カテゴリ・送信者・期間・添付有無で絞り込める。日時・送信者・件名で並べ替えできる
8. 書き出し: CSV（UTF-8 BOM、Excel で化けない、本文は先頭N文字＋改行保持）/ 閲覧用 HTML（カテゴリ別目次つき1ファイル）/ JSON（全項目＋カテゴリ）
9. カテゴリ・ルール・手直し結果は IndexedDB に保存し、同じファイルを読み直すと復元される（キー＝Message-ID、無ければ内容ハッシュ）。設定は JSON で書き出し・読み込みできる
10. 解析に失敗したファイルは一覧に「エラー」として残し、理由を表示する（全体は止めない）
11. 外部へ一切通信しない

### 追加（2026-11-20 実装中のヒヤリングで判明）
- メールの大半はガソリンスタンドの補修依頼。パスワード通知など無関係なメールが混ざる
  → 初期カテゴリ: 対象外（パスワード・自動通知）/ 補修依頼 / 見積・請求 / 完了報告 / その他。「対象外」は書き出しから既定で除外
- 依頼の詳細は添付 xlsx にある → xlsx を詳細画面で表として表示し、セルの文字を検索・自動分類・CSV（「添付xlsxの内容」列）の対象にする。日付セルは yyyy/mm/dd で出す
- 画像の添付がある → 詳細画面に縮小表示（PNG/JPEG/GIF/BMP/WebP。TIFF は保存のみ）
- 「補修依頼」「修理依頼」など言い回しが揺れる → 比較前に NFKC・小文字化・空白除去で表記をそろえる。初期ルールに言い換えを並べる。詳細画面に当てはまった語を出す

## 非目標
- Outlook の .pst / .ost、.eml の読み込み（.msg のみ）
- AI による分類、外部 API 連携
- メールの送信・返信・編集、.msg への書き戻し
- 添付ファイルの ZIP 一括保存（選ばれなかったため。必要になれば追加）
- 添付ファイルのうち xlsx 以外（.xls / Word / PDF 等）の中身の解析・全文検索
- 暗号化（S/MIME）・署名付きメールの復号
- サーバー・ログイン・複数人共有

## 構成（触るファイル）
```
emali-data-exstract/
├─ .claude/CLAUDE.md            static-zero テンプレから作成
├─ .claude/specs/msg-extract/   requirements / design / tasks
├─ index.html                   画面（一覧・詳細・カテゴリ/ルール管理・書き出し）
├─ js/cfb.js                    OLE 複合ファイル(CFB)の読み取り（FAT/MiniFAT/ディレクトリ）
├─ js/msg.js                    MAPI プロパティ解析（__substg1.0_XXXXYYYY、__properties_version1.0、受信者・添付ストレージ、埋め込み msg）
├─ js/xlsx.js                  添付 xlsx の読み取り（ZIP 自前 + DecompressionStream）
├─ js/rtf.js                    圧縮RTF(LZFu)の展開＋RTF内HTML(\fromhtml)の取り出し
├─ js/classify.js               ルール評価
├─ js/store.js                  IndexedDB 保存
├─ js/export.js                 CSV/HTML/JSON 書き出し
├─ css/style.css
└─ tests/                       Node でのテスト（依存ゼロ、node:test）
   ├─ make-msg.mjs             テスト用 .msg 生成器（CFB 書き出し。日本語・添付・埋め込みmsg・RTFのみ等）
   └─ *.test.mjs
```
- `file://` で動かすため ES Modules は使わず、通常の `<script>` で読み込む（Node テストからは `globalThis` 経由で読む）
- 1000件対応: ファイルは1件ずつ解析し、本文・添付の実体はメモリ上の参照のみ保持。一覧は仮想スクロールではなくページング（100件/頁）で軽く保つ

## 主要プロパティ
| 項目 | プロパティ |
|---|---|
| 件名 | 0x0037 |
| 送信者 | 0x0C1A(名) / 0x5D01・0x0C1F(アドレス、EX形式ならSMTPを優先) |
| To/Cc/Bcc | 受信者ストレージの 0x0C15(種別) 0x3001 0x39FE/0x3003。0x0E04/0x0E03/0x0E02 を補助 |
| 送信/受信日時 | 0x0039 / 0x0E06（FILETIME） |
| 本文 | 0x1000 テキスト / 0x1013 HTML / 0x1009 圧縮RTF |
| ヘッダ | 0x007D（Message-ID・In-Reply-To はここから） |
| 重要度 | 0x0017 |
| 添付 | 0x3707/0x3704 名前、0x3701 本体（埋め込みは 0x3701 がストレージ）、0x370E MIME、0x3712 Content-ID |
| 文字コード | 0x3FFD(InternetCPID) / 0x3FDE |

## 検証
- 実物サンプルが無いため、`tests/make-msg.mjs` で以下の .msg を生成し `node --test tests/` で解析結果を照合
  - Unicode 版・ANSI(Shift_JIS)版、To/Cc/Bcc 複数、添付3件（大容量で MiniFAT 境界超え）、埋め込み msg、RTF のみの本文、HTML 本文
- 公開されている .msg テスト用ファイル（OSS ライブラリのテスト資材。MIT 等）があれば取得して照合に加える
- 1000件の生成ファイルをブラウザでドロップし、進捗・所要時間・メモリを確認（Playwright＋簡易サーバー、または claude-in-chrome）
- CSV を Excel 想定で BOM・改行・カンマ入り件名を確認
- 実物での最終確認はユーザーに依頼（数件ドロップして化け・欠けがないか）
