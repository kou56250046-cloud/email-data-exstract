# 分類ごとの割合と評価データの配分試算、集計の HTML 保存

## Context
- 今の集計画面は件数だけの 3 表（主×副 / 月別×主 / SS 別×主）と、表ごとの CSV（`js/summary.js`, `js/app.js:1016 renderSummary`）
- 最終目的: **評価データをどの分類から、どのくらいの割合で集めるかの方針を決める**。そのため件数より「分類ごとの割合」を見たい
- 集計を HTML で保存したい（グラフ・表つき）。**集計だけ**の出力もできるようにする
- 前の仕様の非目標「グラフ描画ライブラリ」は守る。SVG を文字列で組み立てる（依存ゼロ）
- 規模 M。承認後 `.claude/specs/summary-report.md` に写す

## 受入条件
1. **割合の表示**
   - 主カテゴリ・副カテゴリそれぞれの「件数・割合（%）」の表と、構成を示す横棒グラフ
   - 主×副の表に表示の切り替え: 件数 / 全体に占める割合 / 行（主）の中の割合。濃淡は表示中の値に合わせる
   - 割合は小数 1 桁。分母（何件のうちか）を表の上に明記する
2. **評価データの配分試算**（集計画面の新しい節）
   - 入力: 層（主 / 副 / 主×副）、集めたい総件数 N、方式
   - 方式: ①比例配分（母集団の割合どおり）②均等（各層同数）③比例＋最低件数（各層に最低 k 件を確保し、残りを比例で配る）
   - 出力表: 層・母数・母集団の割合・配分件数・配分の割合・不足（母数 < 配分件数のとき）
   - 配分件数の合計は必ず N（端数は最大剰余法で配る）。N が母数合計を超える、③で k×層数 > N などは注記を出す
   - 比例配分で 0 件になる層があれば「この層は評価に入らない」と注記する
   - CSV 書き出しあり
3. **HTML 保存**（集計画面の「HTML で保存」）
   - 選択: 「集計だけ」（既定）/「集計＋メール一覧」（一覧部分は既存の `MsgExport.toHtml` の中身を付ける）
   - 集計の中身: 作成日時、集計の条件（絞り込みの内容・対象外を含めたか・重複を 1 件にしたこと）、割合の表とグラフ、主×副（件数と全体比の 2 枚）、配分試算（画面で選んだ設定で）、月別・SS 別の表、月別の積み上げ棒グラフ
   - スクリプトを入れない。CSP は `default-src 'none'; style-src 'unsafe-inline'`（既存の `toHtml` と同じ）。外部の画像・フォントを読まない
   - 件数・割合は画面の集計と一致する。印刷（A4 横）で崩れない
4. グラフは縦軸 0 始まり、値を文字でも表示、凡例はグラフの隣、色だけで区別しない
5. 外部へ通信しない。`index.html` 1 ファイルで動く（現状どおり）

## 非目標
- 評価データの実際の抜き出し（無作為抽出してメールを書き出す機能）。今回は方針を決めるための試算まで。次の候補
- ネイマン配分など、層ごとのばらつきを使う配分方式
- 案件の進み具合、曜日・時間帯、送信者別の分析
- グラフ描画ライブラリ・`~/.claude/skills/dashboard/assets/dash.js` の取り込み
- 保存した HTML の中での操作（並べ替え・絞り込み・ツールチップ）
- PDF・画像での保存（必要なら HTML を印刷→PDF）
